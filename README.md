## Overview

Ultra Girl : Ether started as a personal modification of the original Ultra Girl project. The goal was to create a more challenging gameplay experience while experimenting with new mechanics and game design ideas.

### Changes

- Increased difficulty
- Fall damage system added
- Additional boss attack
- Ambient fireball added
